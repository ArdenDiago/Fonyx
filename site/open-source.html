Taking part

Found a problem? Say so.

Open an issue with what you did, what you expected and what happened. Your distribution and the output of sonicforge system doctor help a lot.

Changes arrive as pull requests.

Work on a branch and open a pull request. Every one is built and run through the full test suite automatically, and has to pass before it can be merged.

You can run the same checks first:

$ cargo test --workspace
$ sh ui/tests/run-isolated.sh

The second command starts a throwaway audio session of its own, so the tests never touch the sound on your machine.

The code is in five parts.

  • daemon/: the mixer itself, in Rust. Audio engine, processing, and the control interface.
  • ui/: the desktop app. A Tauri shell around a single HTML file.
  • cli/ and client/: the sonicforge command and the connection it shares with the app.
  • quickshell/: the status-bar widget and its standalone app.
  • docs/: how it all works, and why it was built that way.

So is this website.

The desk is drawn with three.js and the pages are bundled with Vite. The typefaces are Fraunces, Hanken Grotesk, JetBrains Mono, Michroma and Caveat, all under the SIL Open Font License.

The desk is an invention for these pages. It is not a real product, and it is not modelled on anyone's hardware.

The demo's music is free too.

The songs in the demo were given to the public domain by their makers under CC0: Beach, Chillin' Poupi and The Strawberry by Komiku, and the Aria from Bach's Goldberg Variations played by Kimiko Ishizaka for the Open Goldberg Variations. They were taken from Wikimedia Commons.
